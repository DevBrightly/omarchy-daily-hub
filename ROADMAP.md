# Roadmap

## Tasks and daily planning

- Big 3 priorities and regular daily tasks
- Later/backlog list and Today/Later movement
- automatic carry-over with carry counts
- descriptions, editing, reordering, and reprioritization
- 14-day history, streaks, and lifetime totals
- quick capture, search, and filtering

## Focus

- configurable focus, short-break, and long-break cycles
- automatic cycle advancement and desktop notifications
- task-associated sessions
- daily focus totals and session history

## Projects

- local repository discovery and Git status
- GitHub repository browsing and cloning
- terminal, editor, Lazygit, and GitHub actions
- coding-agent launch and active-session status
- favourites, recent projects, notes, and next actions
- issue and pull-request summaries

Features will be released incrementally. Existing local state will be migrated
forward as the data model evolves.
